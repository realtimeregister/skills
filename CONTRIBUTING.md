# Contributing
We appreciate your interest and contributions to our project.

## How you can contribute
- **Report issues** - Please [create an issue on GitHub](https://github.com/realtimeregister/skills/issues/new).
- **Submit pull requests** - If you have a fix or improvement, please submit a pull request.
- **Suggest new skills** - If you have a new skill you would like to see added, please [create an issue on GitHub](https://github.com/realtimeregister/skills/issues/new).
